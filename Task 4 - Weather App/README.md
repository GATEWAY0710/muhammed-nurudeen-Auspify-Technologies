# Task 4: Weather Information App

## Description
A Python application that fetches real-time weather information using the OpenWeatherMap API with a clean GUI interface.

## Features
- City search
- Real-time weather data
- Temperature in Celsius
- Weather description
- Humidity and wind speed display
- Error handling for API failures
- Network error handling

## How to Run
1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Open `weather_app.py` and replace `YOUR_API_KEY_HERE` with your API key
3. Install required package: `pip install requests`
4. Run: `python weather_app.py`

## Skills Learned
- REST APIs
- JSON Handling
- Requests Library
- Tkinter GUI
- Error Handling
- API Integration

## Requirements
- Python 3.x
- requests library
